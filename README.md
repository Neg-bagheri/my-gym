# My Gym

Website für ein kleines Fitnessstudio. Das ist ein Übungsprojekt, mit dem ich HTML, CSS und JavaScript geübt habe. Alle Inhalte (Namen, Preise, Adresse) sind frei erfunden.

## Was die Seite kann

- Responsives Layout für Handy und Desktop (CSS Grid und Flexbox)
- Menü mit Burger-Button auf dem Handy
- Anzeige, ob das Studio gerade geöffnet ist, und der heutige Tag in den Öffnungszeiten wird markiert
- Kurse nach Wochentag filtern
- BMI-Rechner
- Kontaktformular mit Prüfung von Name und E-Mail und Fehlermeldungen (noch ohne echten Versand)
- Häufige Fragen mit `<details>`

## Ordner

```
css/style.css      alle Styles
html/index.html    die Seite
js/scripts.js      die Funktionen
source/images/     Bilder
```

Zum Starten `html/index.html` im Browser öffnen oder mit der VS-Code-Erweiterung Live Server starten.

## Was ich dabei gelernt habe

- Layouts mit Grid und Flexbox, auch für verschiedene Bildschirmgrößen
- Elemente im DOM suchen und mit Event Listenern darauf reagieren
- Formulare prüfen und Fehlermeldungen anzeigen
- Auf Tastatur-Bedienung und Lesbarkeit achten (Fokus-Rahmen, Kontraste, `aria`-Attribute)
